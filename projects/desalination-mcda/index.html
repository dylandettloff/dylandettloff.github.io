From inputs to rankings

Community CSV → salinity screening → sampled technology parameters → scenario adjustments → 11 criterion scores → weighted sums → win rates and average ranks.

The research covers reverse osmosis, electrodialysis, humidification–dehumidification, and multi-stage passive distillation; five community contexts; and five future scenarios.

What I built

The research notebook contains the community schema, parameter parsers, feasibility screen, scoring rules, financial and carbon calculations, and Monte Carlo ranking model. This portfolio adds a command-line entry point and a browser viewer.

How to interpret the results

These are illustrative community profiles. Thermal-energy accounting, unknown capital costs, and technology maturity are incomplete. The operator-capacity scale has conflicting descriptions, and clipping then normalizing sampled weights can move them outside the intended bounds. The original model is preserved, with these limitations documented.

Reproduce a small run

python -m pip install -r requirements.txt
python run.py --parameters 20 --weights 50 --seed 7

Run from the project folder with Python 3.11+. The small run is a smoke test and will differ from the historical CSV. See the README for the original notebook’s larger run settings.
